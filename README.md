# Feature Engineering and Exploratory Data Analysis on Delhivery Logistics Dataset

## Overview
This repository contains a comprehensive Exploratory Data Analysis (EDA) and Feature Engineering workflow on a synthetic dataset from Delhivery, a leading logistics service provider in India.  
The goal of this project is to extract actionable insights from operational data and propose data-backed performance improvement strategies to enhance logistics efficiency and customer satisfaction.

## Objectives
- Understand data characteristics and structure.  
- Identify operational bottlenecks through EDA.  
- Engineer meaningful features.  
- Provide recommendations grounded in quantitative analysis.
